# SQL Payments 💳

Projeto de análise de pagamentos desenvolvido para demonstrar conhecimentos em SQL, modelagem de dados e análise de informações.

## 🎯 Objetivo

Criar uma base de dados fictícia de clientes e pagamentos e utilizar SQL para gerar análises e indicadores que poderiam apoiar decisões de negócio.

## 🛠️ Tecnologias utilizadas

- SQL
- Modelagem de dados
- Consultas SQL
- Agregações e métricas
- Análise de dados

---

## 📊 Principais análises

O projeto permite analisar:

- Total de pagamentos
- Valor total movimentado
- Pagamentos por status
- Pagamentos por cliente
- Ticket médio
- Pagamentos por período
- Clientes com maior volume financeiro

---

## 💡 Insights

A partir das consultas SQL, é possível identificar padrões de pagamentos, volume financeiro, comportamento dos clientes e indicadores que podem apoiar decisões de negócio.
